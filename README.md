# Coffee Sales Dashboard
This project features data cleaning, pivot tables/charts, slicers, and data visualization utilizing coffee sales data. It employs advanced Excel techniques to clean raw data and analyze how coffee sales performed over time and in different contexts (such as sales based on country or for the top customers).


#### -- Project Status: [Complete]

___

### Objectives
The purpose of the project is to:
 - Clean and deduplicate raw data
 - Construct pivot tables, pivot charts, and slicers
 - Analyze coffee sales across top countries, top customers, and over time
 - Create a detailed dashboard for stakeholder presentation

### Technologies
 - Microsoft Excel

### Methods
- Data Cleaning (XLOOKUP, INDEX, MATCH, and IF)
- Pivot Tables and Charts
- Slicers
- Data Visualization

___

### Steps
1) Cleaned data in Microsoft Excel using functions like XLOOKUP, INDEX, MATCH, and IF
2) Generated pivot tables and charts to analyze the sales data 
3) Implemented an interactive timeline (for Order Date) and slicers (for Size, Roast Type Name, and Loyalty Card) to filter sales data
4) Organized a dashboard for reporting and presentation for stakeholder review

___

### Key Insights
- The most amount of total sales were made the by Arabica in September 2021 ($841) and Liberica in January 2022 ($844).
- The United States had the highest amount of sales compared to Ireland and the United Kingdom, where the maximum total sales difference was 18%.
- The top 5 customers of the coffee sales were Allis Wilmore, Brenn Dundredge, Terri Farra, Nealson Cuttler, and Don Flintiff.
